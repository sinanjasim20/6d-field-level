# 6D مناسيب الموقع لايت

تطبيق أندرويد لحساب قراءات المسطرة ومناسيب طبقات الطريق في الموقع، يعمل على الهاتف وحده دون إنترنت ودون حساب.

- استيراد البروفايل من ملف PDF (Civil 3D) أو Excel
- إدخال مواصفات الشارع مرة واحدة
- القراءة المطلوبة على المسطرة لكل محطة وطبقة، مع القطع والردم
- متابعة نسبة الإنجاز لكل طبقة
- تصدير التقرير Excel أو PDF
