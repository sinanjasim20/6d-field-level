# 6D مناسيب الموقع

تطبيق لحساب قراءات المسطرة ومناسيب طبقات الطريق في الموقع. يعمل دون إنترنت، والحساب اختياري.

- مشروع واحد يضم كل شوارعه، واستيراد عدة ملفات مرة واحدة
- استيراد البروفايل من ملف PDF (Civil 3D) أو Excel، وإحداثيات الشوارع من تقرير محطات المحاور
- القراءة المطلوبة على المسطرة لكل محطة وطبقة، مع القطع والردم
- الخدمات (أنابيب وكابلات) ومناسيبها
- أقرب محطة من موقع الهاتف، ونسبة الإنجاز لكل طبقة
- تصدير التقرير Excel أو PDF

## بحساب أو بدونه

- **بدون حساب:** يعمل كاملاً دون إنترنت، وعملك على هاتفك فقط.
- **بحسابك في Google (اختياري):** نسخة احتياطية تلقائية على Google Drive الخاص بك.
- **مع فريق (اختياري):** شارك المشروع مع فريقك، وكل «تمت» تظهر عند الجميع مباشرة.
